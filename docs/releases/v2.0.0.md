GraphPrime 2.0.0 modernizes the application with Tauri 2, Svelte 5 and Rust 2024. This rebuilt release replaces the original 2.0.0 packages to fix Linux startup and interface regressions.

## Fixes in the rebuilt release

- **Linux AppImage startup:** fixed `Could not create default EGL display: EGL_BAD_PARAMETER. Aborting...` on newer Linux distributions. The AppImage now uses the host Wayland libraries with the host graphics drivers, without forcing software rendering.
- **Restored interface styles:** local stylesheets and dynamic styles from CodeMirror and the chart libraries are allowed. Automatic CSP hash injection is disabled for styles, while CSP remains enabled for other resources.
- **Working clipboard:** removed the obsolete isolation iframe and consolidated Tauri 2 permissions for clipboard writes from the local application window.
- **Calculation feedback:** failed calculations display an error and preserve the last successful results. The Calculate button prevents duplicate requests while a calculation runs.
- **Small limits:** calculations now exclude primes above the requested limit, including the empty sequence for 1 and the single prime for 2.
- **macOS Intel packages:** Intel and Apple Silicon builds now use their correct targets and produce separate downloads.
- **Release verification:** added Rust calculation tests and a Linux package test that opens the real application, checks styling and prime sequences, switches graphs, exercises fullscreen controls and checks the native clipboard. All platform builds must succeed before the release assets are uploaded.

## Changes since 1.0.5

- Migrated the desktop runtime to Tauri 2 and the interface to Svelte 5 runes.
- Replaced the legacy Frappe Charts wrapper with a native Svelte component.
- Updated Rust to the 2024 edition and refreshed frontend dependencies.
- Improved dark-mode controls and composite-number statistics.
- Removed the legacy auto-updater. Install updates manually from GitHub Releases.

## Downloads

- **Linux:** `.AppImage`, `.deb`, or `.rpm`. Make the AppImage executable before opening it.
- **Windows:** `.msi` or `-setup.exe`.
- **macOS:** choose the `aarch64` download for Apple Silicon or `x64` download for Intel.

If you downloaded the original 2.0.0 packages, download the rebuilt files again. `SHA256SUMS` contains checksums for all packages.
