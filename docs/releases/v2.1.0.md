GraphPrime 2.1.0 refreshes the desktop runtime and frontend tooling, improves editor and chart updates, and adds automated checks against performance regressions.

## Changes

- Updated to Tauri 2.11, Svelte 5.57 and Rust 1.98.1, with refreshed JavaScript and Rust dependencies.
- Replaced Rollup with Vite and the official Svelte plugin. Development now uses Node.js 24 and Yarn 4.
- Reused CodeMirror and scientific chart instances when updating results or toggling fullscreen, and cleaned them up when their components close.
- Removed obsolete build plugins and unused direct dependencies while preserving the prime calculation algorithm and existing interface.
- Added paired performance benchmarks for calculation and JSON serialization against the repaired 2.0.0 implementation. Desktop builds and releases fail when the regression threshold is exceeded.
- Consolidated CodeQL analysis for Rust, JavaScript/TypeScript, Python and GitHub Actions, made Rust formatting and Clippy required checks, and avoided duplicate desktop builds for internal pull requests.
- Kept Linux AppImage startup, dynamic styles and clipboard fixes from the rebuilt 2.0.0 release. Package tests exercise calculations, both graphs, fullscreen controls and the native clipboard.
- Made macOS application archives architecture-specific and kept release notes under version control.

## Downloads

- **Linux:** `.AppImage`, `.deb`, or `.rpm`. Make the AppImage executable before opening it.
- **Windows:** `.msi` or `-setup.exe`.
- **macOS:** choose `aarch64` for Apple Silicon or `x64` / `x86_64` for Intel.

Updates remain manual. `SHA256SUMS` contains checksums for all release packages.

The dependency refresh resolves the audited Cargo vulnerability-list entries and npm advisories. Upstream GTK/GLib soundness and unmaintained-crate warnings remain documented in [dependency maintenance](https://github.com/DoodlesEpic/GraphPrime/blob/v2.1.0/docs/dependencies.md).
